<p id="mwBA"><b id="mwBQ">HTML5</b> (<a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Hypertext_Markup_Language" title="Hypertext Markup Language" class="mw-redirect" id="mwBg">Hypertext Markup Language</a>, versão 5) é uma <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Linguagem_de_marcação" title="Linguagem de marcação" id="mwBw">linguagem de marcação</a> para a <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/World_Wide_Web" title="World Wide Web" id="mwCA">World Wide Web</a> e é uma tecnologia chave da Internet, originalmente proposto por <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Opera_Software" title="Opera Software" id="mwCQ">Opera Software</a>.<sup about="#mwt6" class="mw-ref reference" id="cite_ref-1" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-1"}}'><a href="#cite_note-1" id="mwCg"><span class="mw-reflink-text" id="mwCw"><span class="cite-bracket" id="mwDA">[</span>1<span class="cite-bracket" id="mwDQ">]</span></span></a></sup> É a quinta versão da linguagem <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/HTML" title="HTML" id="mwDg">HTML</a>. Esta versão traz consigo importantes mudanças quanto ao papel do HTML no mundo da Web, através de novas funcionalidades como semântica e <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Acessibilidade" title="Acessibilidade" id="mwDw">acessibilidade</a>. Possibilita o uso de recursos antes possíveis apenas com a aplicação de outras tecnologias. Sua essência tem sido melhorar a linguagem com o suporte para as mais recentes multimídias, enquanto a mantém facilmente legível por seres humanos e consistentemente compreendida por computadores e outros dispositivos (<a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Navegadores" title="Navegadores" class="mw-redirect mw-disambig" id="mwEA">navegadores</a>, parsers etc). O HTML5 é o padrão atual para HTML, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/XHTML" title="XHTML" id="mwEQ">XHTML</a>, e HTML DOM. </p>

<p id="mwEg">Após seus predecessores imediatos HTML 4.01 e XHTML 1.1, HTML5 é uma resposta à observação de que o HTML e o XHTML, de uso comum na <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/World_Wide_Web" title="World Wide Web" id="mwEw">World Wide Web</a>, é uma mistura de características introduzidas por várias especificações, juntamente com aquelas introduzidas por software, tais como os navegadores, aqueles estabelecidos pela prática comum, e os muitos erros de sintaxe em documentos existentes na web. É, também, uma tentativa de definir uma única linguagem simples de marcação que possa ser escrita em HTML ou em sintaxe XHTML. Isso inclui modelos de processamento detalhados para incentivar implementações mais interoperáveis; isso estende, melhora e racionaliza a marcação disponível para documentos, e introduz marcações e <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Interface_de_programação_de_aplicações" title="Interface de programação de aplicações" id="mwFA">interfaces de programação de aplicações</a> (APIs) para <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Aplicação_web" title="Aplicação web" id="mwFQ">aplicações web</a> complexas. Pelas mesmas razões, HTML5 também é um candidato em potencial aplicações <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Multiplataforma" title="Multiplataforma" id="mwFg">multi-plataforma</a> móveis. Muitos recursos do HTML5 tem sido construídos com a consideração de ser capaz de executar em dispositivos de baixa potência como <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Smartphone" title="Smartphone" id="mwFw">smartphones</a> e tablets.<sup about="#mwt8" class="mw-ref reference" id="cite_ref-diff_2-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"diff"},"body":{"id":"mw-reference-text-cite_note-diff-2"}}'><a href="#cite_note-diff-2" id="mwGA"><span class="mw-reflink-text" id="mwGQ"><span class="cite-bracket" id="mwGg">[</span>2<span class="cite-bracket" id="mwGw">]</span></span></a></sup></p>

<p id="mwHA">Em particular, HTML5 adiciona várias novas funções sintáticas. Elas incluem as tags de <code id="mwHQ"><span typeof="mw:Entity" id="mwHg">&lt;</span>video></code>, <code id="mwHw"><span typeof="mw:Entity" id="mwIA">&lt;</span>audio></code>, <code id="mwIQ"><span typeof="mw:Entity" id="mwIg">&lt;</span>header></code> e elementos <code id="mwIw"><span typeof="mw:Entity" id="mwJA">&lt;</span><a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Canvas_(HTML5)" title="Canvas (HTML5)" id="mwJQ">canvas</a>></code>, assim como a integração de conteúdos <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/SVG" title="SVG" id="mwJg">SVG</a> que substituem o uso de tags <code id="mwJw"><span typeof="mw:Entity" id="mwKA">&lt;</span>object></code> genéricas. Estas funções são projetadas para tornar mais fácil a inclusão e a manipulação de conteúdo gráfico e multimídia na web sem ter de recorrer a <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Plugins" title="Plugins" class="mw-redirect" id="mwKQ">plugins</a> <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Software_proprietário" title="Software proprietário" id="mwKg">proprietários</a> e APIs. Outros novos elementos, como <code id="mwKw"><span typeof="mw:Entity" id="mwLA">&lt;</span>section></code>, <code id="mwLQ"><span typeof="mw:Entity" id="mwLg">&lt;</span>article></code>, <code id="mwLw"><span typeof="mw:Entity" id="mwMA">&lt;</span>header></code> e <code id="mwMQ"><span typeof="mw:Entity" id="mwMg">&lt;</span>nav></code>, são projetados para enriquecer o conteúdo semântico dos documentos. Novos atributos têm sido introduzidos com o mesmo propósito, enquanto alguns elementos e atributos têm sido removidos. Alguns elementos, como <code id="mwMw"><span typeof="mw:Entity" id="mwNA">&lt;</span>a></code>, <code id="mwNQ"><span typeof="mw:Entity" id="mwNg">&lt;</span>cite></code> e <code id="mwNw"><span typeof="mw:Entity" id="mwOA">&lt;</span>menu></code> têm sido mudados, redefinidos ou padronizados. As APIs e os modelos de objetos de documentos (<a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Modelo_de_Objeto_de_Documentos" title="Modelo de Objeto de Documentos" id="mwOQ">DOM</a>) não são mais pensamentos retrógrados, mas são partes fundamentais da especificação do HTML5.<sup about="#mwt9" class="mw-ref reference" id="cite_ref-diff_2-1" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"diff"}}'><a href="#cite_note-diff-2" id="mwOg"><span class="mw-reflink-text" id="mwOw"><span class="cite-bracket" id="mwPA">[</span>2<span class="cite-bracket" id="mwPQ">]</span></span></a></sup> HTML5 também define com algum detalhe o processamento necessário para que erros de sintaxe de documentos inválidos sejam tratados uniformemente por todos os browsers e outros agentes de usuários em conformidade com o HTML5.<sup about="#mwt11" class="mw-ref reference" id="cite_ref-3" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-3"}}'><a href="#cite_note-3" id="mwPg"><span class="mw-reflink-text" id="mwPw"><span class="cite-bracket" id="mwQA">[</span>3<span class="cite-bracket" id="mwQQ">]</span></span></a></sup></p>

<meta property="mw:PageProp/toc" id="mwQg" data-mw='{"autoGenerated":true}'/></section><section data-mw-section-id="1" id="mwQw" aria-labelledby="História"><div class="mw-heading mw-heading2"><h2 id="História"><span id="Hist.C3.B3ria" typeof="mw:FallbackId"></span>História</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=HTML5&amp;veaction=edit&amp;section=1" title="Editar secção: História" class="mw-editsection-visualeditor"><span>editar</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=HTML5&amp;action=edit&amp;section=1" title="Editar código fonte da secção: História"><span>editar código</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p id="mwRA">O <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Web_Hypertext_Application_Technology_Working_Group" title="Web Hypertext Application Technology Working Group" class="mw-redirect" id="mwRQ">Web Hypertext Application Technology Working Group</a> (WHATWG) iniciou o trabalho do novo padrão HTML em 2004, quando o <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/World_Wide_Web_Consortium" title="World Wide Web Consortium" class="mw-redirect" id="mwRg">World Wide Web Consortium</a> (W3C) estava se concentrando no futuro desenvolvimento do <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/XHTML#XHTML_2.0" title="XHTML" id="mwRw">XHTML 2.0</a>, e o HTML 4.01 não tinha sido atualizado desde 2001.
<sup about="#mwt13" class="mw-ref reference" id="cite_ref-4" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-4"}}'><a href="#cite_note-4" id="mwSA"><span class="mw-reflink-text" id="mwSQ"><span class="cite-bracket" id="mwSg">[</span>4<span class="cite-bracket" id="mwSw">]</span></span></a></sup>
Em 2009, o W3C decidiu que o Grupo de Trabalho do XHTML 2.0 deveria parar seus trabalhos, e assim, descontinuar o padrão. Desta forma o W3C e o WHATWG passaram a trabalhar juntas no desenvolvimento do HTML5.
<sup about="#mwt15" class="mw-ref reference" id="cite_ref-5" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-5"}}'><a href="#cite_note-5" id="mwTA"><span class="mw-reflink-text" id="mwTQ"><span class="cite-bracket" id="mwTg">[</span>5<span class="cite-bracket" id="mwTw">]</span></span></a></sup></p>

<p id="mwUA">O projeto do HTML5 foi bem recebido pelos desenvolvedores Web até então, e tornou-se tema na mídia em abril de 2010
<sup about="#mwt17" class="mw-ref reference" id="cite_ref-6" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-6"}}'><a href="#cite_note-6" id="mwUQ"><span class="mw-reflink-text" id="mwUg"><span class="cite-bracket" id="mwUw">[</span>6<span class="cite-bracket" id="mwVA">]</span></span></a></sup><sup about="#mwt19" class="mw-ref reference" id="cite_ref-7" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-7"}}'><a href="#cite_note-7" id="mwVQ"><span class="mw-reflink-text" id="mwVg"><span class="cite-bracket" id="mwVw">[</span>7<span class="cite-bracket" id="mwWA">]</span></span></a></sup> depois que o CEO da <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Apple_Inc." title="Apple Inc." class="mw-redirect" id="mwWQ">Apple Inc.</a>, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Steve_Jobs" title="Steve Jobs" id="mwWg">Steve Jobs</a> emitiu uma carta pública intitulada "Reflexões sobre o Adobe Flash", onde ele conclui que o desenvolvimento do HTML5 tornaria o <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Adobe_Flash" title="Adobe Flash" id="mwWw">Adobe Flash</a> desnecessário, tanto para assistir vídeo ou mesmo exibir qualquer conteúdo web. Isso provocou um debate entre os desenvolvedores Web, onde muitos sugeriram que, enquanto o HTML5 proporcionasse uma melhor funcionalidade, a variedade de browsers existentes exibiria páginas diferentes, tendo um resultado diferente em cada navegador e não se conseguiria de fato chegar a um padrão.<sup about="#mwt21" class="mw-ref reference" id="cite_ref-8" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-8"}}'><a href="#cite_note-8" id="mwXA"><span class="mw-reflink-text" id="mwXQ"><span class="cite-bracket" id="mwXg">[</span>8<span class="cite-bracket" id="mwXw">]</span></span></a></sup> No início de novembro de 2011 a Adobe anunciou que iria interromper o desenvolvimento de <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Adobe_Flash" title="Adobe Flash" id="mwYA">Flash</a> para dispositivos móveis e redirecionar seus esforços para o desenvolvimento de ferramentas utilizando HTML5.</p>

</section><section data-mw-section-id="2" id="mwYQ" aria-labelledby="Descrição"><div class="mw-heading mw-heading2"><h2 id="Descrição"><span id="Descri.C3.A7.C3.A3o" typeof="mw:FallbackId"></span>Descrição</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=HTML5&amp;veaction=edit&amp;section=2" title="Editar secção: Descrição" class="mw-editsection-visualeditor"><span>editar</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=HTML5&amp;action=edit&amp;section=2" title="Editar código fonte da secção: Descrição"><span>editar código</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p id="mwYg">No início de 2008 o <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/W3C" title="W3C" id="mwYw">W3C</a> – consórcio de empresas de tecnologia que coordena os padrões da internet quanto a linguagem – anunciou a primeira especificação do <b id="mwZA">HTML5</b>. O HTML, responsável por organizar e formatar as páginas que visitamos na Internet, está em sua versão 4.0.1 e continua evoluindo. Após cinco anos de trabalho, desde 2008 está em fase de esboço, enquanto a versão final está prevista para 2014. Foram feitas grandes alterações, que incluem:</p>

<ul id="mwZQ"><li id="mwZg">Novas <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Interface_de_programação_de_aplicações" title="Interface de programação de aplicações" id="mwZw">API</a>’s, entre elas uma para desenvolvimento de gráficos bidimensionais</li>
<li id="mwaA">Controle embutido de conteúdo multimídia</li>
<li id="mwaQ">Aprimoramento do uso offline</li>
<li id="mwag">Melhoria na <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Depuração" title="Depuração" id="mwaw">depuração</a> de erros</li></ul>

<p id="mwbA">Esta evolução da linguagem padrão para web pode eliminar a necessidade de <i id="mwbQ"><a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Plug-in" title="Plug-in" id="mwbg">plug-ins</a></i> para aplicações <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Multimídia" title="Multimídia" class="mw-redirect" id="mwbw">multimídia</a> em navegadores. Diversos críticos consideram a tecnologia como um forte concorrente ao <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Adobe_Flash" title="Adobe Flash" id="mwcA">Flash</a>, da <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Adobe_Systems" title="Adobe Systems" class="mw-redirect" id="mwcQ">Adobe</a>, ao <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Silverlight" title="Silverlight" id="mwcg">Silverlight</a>, da <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Microsoft" title="Microsoft" id="mwcw">Microsoft</a>, e ao recente <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/JavaFX" title="JavaFX" id="mwdA">JavaFX</a>, da <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Sun_Microsystems" title="Sun Microsystems" id="mwdQ">Sun</a> (<a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Oracle_Corporation" title="Oracle Corporation" id="mwdg">Oracle</a>). Recentemente, Shantanu Narayen, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Diretor_executivo" title="Diretor executivo" class="mw-redirect" id="mwdw">diretor executivo</a> da Adobe, disse que o Flash não iria perder mercado, porém a versão 5 do HTML já está sendo chamada de "<i id="mweA">Flash-killer</i>" (Assassino do Flash). Estas tecnologias precisarão se adaptar rapidamente para conseguir manter-se no mercado, tão populares quanto hoje. Na avaliação do co-diretor de ferramentas da <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Mozilla_Foundation" title="Mozilla Foundation" id="mweQ">Mozilla</a>, Ben Galbraith, as tecnologias viabilizadas pelo HTML5 como o <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Canvas_(HTML5)" title="Canvas (HTML5)" id="mweg">Canvas</a> para desenhos 2D e o armazenamento de conteúdos no desktop, permitirão que "<i id="mwew">usemos mais o browser do que nunca</i>".</p>

<p id="mwfA">Após dez anos sem atualizações, como se escreve páginas na internet passa por uma boa transformação. O HTML5 oferece uma experiência web totalmente diferente para usuários e embora exista um longo caminho para ser finalizado, muitos navegadores importantes, como <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Internet_Explorer_9" title="Internet Explorer 9" id="mwfQ">Internet Explorer 9</a>, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Opera_(web_browser)" title="Opera (web browser)" class="mw-redirect" id="mwfg">Opera</a>, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Safari_(web_browser)" title="Safari (web browser)" class="mw-redirect" id="mwfw">Safari</a> 4, <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Firefox" title="Firefox" class="mw-redirect" id="mwgA">Firefox</a> 3.6 e <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Google_Chrome" title="Google Chrome" id="mwgQ">Chrome</a> já implementaram grandes partes da linguagem, incluindo tags de vídeo e suporte à tecnologia Canvas. Com a evolução da linguagem, os navegadores passam da categoria "<i id="mwgg">mostradores</i>" de páginas para um renderizador de "<i id="mwgw">web software</i>".</p>

<p id="mwhA">Assim como surgiram as <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Loja_de_aplicativos" title="Loja de aplicativos" id="mwhQ">app stores</a> para aplicações nativas, existem <i id="mwhg">appstores</i> especificas para aplicações HTML5, os desenvolvedores podem utilizar a audiência das appstores para distribuir seu aplicativo e também fazer cobrança (as appstores oferecem integrações para permitir a cobrança). Como, por exemplo, a <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Zeewe?action=edit&amp;redlink=1" title="Zeewe (página não existe)" class="new" typeof="mw:LocalizedAttrs" id="mwhw" data-mw-i18n='{"title":{"lang":"x-page","key":"red-link-title","params":["Zeewe"]}}'>Zeewe</a>, loja de apps HTML5 focada em <a rel="mw:WikiLink" href="https://pt.wikipedia.org/wiki/Smartphone" title="Smartphone" id="mwiA">smartphones</a>.</p>
